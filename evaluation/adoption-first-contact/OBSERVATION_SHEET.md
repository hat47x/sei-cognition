# E-80.1 観測シート

状態: **下書き。観測は未実施。結果はまだない。**

1回の試行につき1枚を使います。この雛形に書かれた内容は、観測の結果ではありません。

- 「テスター」が書く欄と、「観測者が記入」と書いた欄があります。
- 名前、メールアドレス、個人のパス (C:\Users\... や /home/... など) は書かないでください。

## 9. 読み取りの確認 (resume の後)

resume の出力だけを見て、自分の言葉で答えてください。答えられない項目は「答えられない」と書いてください。

| 問い | 本人の回答 (自分の言葉で) | 答えたか | 読み取りの正誤 (観測者が記入) |
|---|---|---|---|
| 1. 何が決まったか。 | | [ ] 答えた　[ ] 答えられなかった | [ ] 正　[ ] 誤　[ ] 一部 |
| 2. 何が未解決のまま残っているか。 | | [ ] 答えた　[ ] 答えられなかった | [ ] 正　[ ] 誤　[ ] 一部 |
| 3. 採用されなかった推薦はどれか。 | | [ ] 答えた　[ ] 答えられなかった | [ ] 正　[ ] 誤　[ ] 一部 |

答えられなかった項目は、導入の完了とは別に、表示の分かりにくさとして §10 に書きます。

- 観測者が記入: 手順書の欠陥として記録した項目:
- 観測者が記入: 表示の分かりにくさとして記録した問い:

## 11. 観測者の確認 (テスターは書かない)

- [ ] 補助なしで、検証まで完了した。補助があった場合は、この項目を満たさない。
- [ ] 作者の端末での実行ではない。
- [ ] 名前、メールアドレス、個人のパスが含まれていない。
- [ ] 止まった箇所も含めて記録した。成功だけを書いていない。
- [ ] 録画した場合は、同意を取っている。

一人分の記録は、導入が容易だという証明にはなりません。

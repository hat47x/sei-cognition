# E-80.1 初期導入の観測手順

更新日: 2026-10-06  
状態: **Protocol only。観測は未実施。結果はまだない**  
関連: **ISSUE-000080 / ADR-0033**

## 1. 目的

SEIの開発に関わっていない人が、空の端末で、書かれた手順だけを使って、最初の判断の記録、再開、第三者による検証までを行えるかを観測します。

この観測が確かめるのは、導入の最初の体験です。SEIの意味構造が正しいことや、利用者に価値が届くことは、この観測では確かめません。

```text
初期導入が完了した
  != 導入が容易である
  != 価値が届いた
```

## 2. 被験者

- SEIの設計、実装、文書作成に関わっていない人。
- AIツールまたは開発ツールを日常的に使う人。開発者か運用担当者を想定する。
- 観測の前に、SEIの文書を読んでいないこと。読んだ場合は、その事実と範囲を記録し、結果の解釈に反映する。

被験者は一人ずつ観測し、観測者の補助は原則として行いません。

## 3. 準備

- 被験者の端末で、`sei`がまだ入っていない状態を使う。作者の端末は使わない。
- 渡すのは、`runtime/go/cmd/sei/QUICKSTART.md`と、バイナリ(または`tools/build_sei.sh`の手順)だけにする。
- 画面と操作を記録する。記録する場合は、被験者の同意を得る。

## 4. 手順と記録

被験者に次の課題を伝えます。

> 二つのAIツールが別々の推薦を出した状況を想定してください。一つを採用する決定を記録し、翌日に別の担当者が続きを始められる状態にして、第三者がその記録を検証できるところまで進めてください。

次の時刻と事象を記録します。

| 記録する項目 | 内容 |
|---|---|
| 開始時刻 | 課題を伝えた時刻 |
| 入手の完了時刻 | `sei version`が動いた時刻 |
| 最初の記録の時刻 | 最初の`add`が成功した時刻 |
| 再開の完了時刻 | `resume`の結果を被験者が読み取れた時刻 |
| 検証の完了時刻 | `verify`が成功した時刻 |
| 手順数 | 実行したコマンドの数と、失敗した数 |
| 事前に必要になったもの | 追加で入れたツール、設定、アカウント |
| つまずき | 止まった箇所、読み直した箇所、被験者の発言 |
| 補助 | 観測者が口を出した内容と時刻 |

## 5. 補助の扱い

- 観測者の補助が一度でも入った課題は、その時点で補助付きとして記録し、補助なしの完了として数えない。
- 被験者が自分で検索した内容は補助に含めず、検索した事実として記録する。
- 手順書の誤りが原因で止まった場合は、手順書の欠陥として記録し、被験者の失敗とは区別する。

## 6. 読み取りの確認

`resume`の後に、次の三つを被験者に口頭で答えてもらいます。

1. 何が決まったか。
2. 何が未解決のまま残っているか。
3. 採用されなかった推薦はどれか。

答えられなかった項目は、導入の完了とは別に、表示の分かりにくさとして記録します。

## 7. 結果の記録

結果は、次の形で`evaluation/adoption-first-contact/`に追記します。被験者の名前は記録せず、識別子だけを残します。

| 項目 | 記録 |
|---|---|
| 被験者ID | |
| 日付 | |
| 端末(OS) | |
| 完了した段階 | 入手 / 最初の記録 / 再開 / 検証 |
| 各段階の所要時間 | |
| 補助の有無と内容 | |
| つまずき | |
| 手順書の欠陥 | |
| 読み取りの正誤 | |

## 8. 結果の読み方

- 固定のしきい値はまだ置かない。15分以内という暫定の探索目標は、最初の観測の後で見直す。
- 一人の結果を、導入の容易性の証明として扱わない。
- 一人でも、補助なしで完了できなかった事実は、手順書、バイナリ、表示のどこを直すかの材料にする。
- 成功だけでなく、止まった箇所の分布を残す。

## 9. 停止線

- 作者の補助付きの導入を、補助なしの完了として記録しない。
- 作者の端末での実行を、観測として数えない。
- 手順書に載っていない口頭の説明を、導入手順として数えない。
- 観測の結果を、Adoption / Outcome Evidenceへ昇格させない。この観測はE-80.1であり、価値の観測ではない。

## 10. Natural Japanese review

観測が確かめることと、確かめないことを分けて書いた。結果を持たない手順であることを状態に明記し、導入の完了と容易性、価値を別のものとして扱っている。

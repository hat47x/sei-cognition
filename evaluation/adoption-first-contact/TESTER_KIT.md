## 4. バイナリの入手と照合

作者が、バイナリと SHA256SUMS を別の経路で送ります。今回は、ソースからのビルドは行いません。届いたバイナリを使ってください。

ファイル名は、次のどれかです。作者から伝えられた名前が違う場合は、その名前を使ってください。

- Windows (64bit): sei-windows-amd64.exe
- macOS (Apple Silicon): sei-darwin-arm64
- macOS (Intel): sei-darwin-amd64
- Linux (64bit Intel/AMD): sei-linux-amd64
- Linux (ARM64): sei-linux-arm64

実行する前に、バイナリの SHA-256 を計算し、SHA256SUMS の同じファイル名の行と比べてください。SHA256SUMS の各行は「ハッシュ値、空白、ファイル名」の形です。

Windows の PowerShell では、バイナリのあるフォルダで次を実行します。

```powershell
Get-FileHash -Algorithm SHA256 .\sei-windows-amd64.exe
```

macOS のターミナルでは、次を実行します。Linux で shasum がない場合は、同じ形で sha256sum を使います (例: sha256sum ./sei-linux-amd64)。

```sh
shasum -a 256 ./sei-darwin-arm64
```

ハッシュ値は、大文字と小文字を区別せずに比べてください。Get-FileHash の出力にはファイルのパスも含まれます。シートに書くときは、ハッシュ値だけを書いてください。

- 一致した場合は、次に進みます。
- 一致しない場合、または SHA256SUMS が手元にない場合は、実行しないでください。シートに、その旨と時刻を書いて、ここで止めてください。
